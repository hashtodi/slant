# Slant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a macOS menu bar app that bends, blurs and dims the live desktop in real time as the MacBook lid closes, driven by the built-in lid-angle sensor.

**Architecture:** An unsandboxed `LSUIElement` agent app. A 120Hz IOHID poll feeds lid angle into a critically-damped spring; a `CADisplayLink` capped at 60fps drives a Metal renderer that inverse-maps each pixel through a 3x3 homography and samples a Gaussian mip pyramid for free blur. The rendered result is drawn into a click-through borderless window at `CGShieldingWindowLevel()` over a live ScreenCaptureKit feed of the built-in display.

**Tech Stack:** Swift 6, Swift Package Manager, IOKit/IOHID, ScreenCaptureKit, Metal, MetalPerformanceShaders, ServiceManagement, AppKit.

**Spec:** `docs/superpowers/specs/2026-09-11-slant-design.md`

## Amendment 2026-09-11: runtime shader compilation

Xcode is not installed on the build machine (Command Line Tools only), so the
offline `metal` compiler is unavailable. The shader is therefore compiled at
runtime with `MTLDevice.makeLibrary(source:options:)`, using the Metal
framework's own runtime compiler, which needs no Xcode.

Consequences:
- `Package.swift` declares `.copy("Fold.metal")`, not `.process(...)`, so the
  file ships verbatim as a resource and is read as a string.
- `FoldRenderer.init` reads `Fold.metal` from `Bundle.module` and compiles it.
  Shader errors surface at launch rather than at build time.
- Reversible: installing Xcode plus the Metal Toolchain component allows
  switching back to `.process` and `makeDefaultLibrary(bundle:)`.

## Global Constraints

- macOS 14+, Apple Silicon only.
- **Unsandboxed.** No `com.apple.security.*` entitlements. App Sandbox blocks `IOHIDManager` vendor/product matching. Non-negotiable.
- `LSUIElement = true`. No Dock icon.
- Built-in display only (`CGDisplayIsBuiltin`). External displays are never rendered to.
- HID match: vendor `0x05AC`, product `0x8104`, usage page `0x0020`, usage `0x008A`.
- Report ID 7 probed first (32-bit little-endian, hundredths of a degree); report ID 1 is fallback only (16-bit little-endian, whole degrees). Both `kIOHIDReportTypeFeature`.
- Frame rate capped to `min(screen.maximumFramesPerSecond, 60)`. Display link paused at rest.
- Ships MIT, with an Apache-2.0 `NOTICE` crediting Mac-Duo (Makito) and LidAngleSensor (Sam Henri Gold).
- Never use the string "iPhone Duo" in product copy. Ship an explicit "not affiliated with Apple" disclaimer.

```swift
import Foundation

/// Parses raw HID feature reports from the MacBook lid-angle sensor.
///
/// Two report formats exist. Report 7 carries hundredths of a degree and is
/// strongly preferred: reading it eliminates whole-degree stepping at the
/// source rather than smoothing it away downstream. Report 1 carries whole
/// degrees and is the fallback for hardware that does not answer report 7.
///
/// Report layouts documented by Sam Henri Gold's LidAngleSensor (report 1)
/// and sumimakito's Mac-Duo (report 7).
public enum LidReport {

    public static let minDegrees: Double = 0
    public static let maxDegrees: Double = 360

    /// Report 7: 5 bytes `[0x07, b0, b1, b2, b3]`, little-endian UInt32,
    /// hundredths of a degree.
    public static func degrees(fromReport7 bytes: [UInt8]) -> Double? {
        guard bytes.count >= 5, bytes[0] == 0x07 else { return nil }
        let raw = UInt32(bytes[1])
            | UInt32(bytes[2]) << 8
            | UInt32(bytes[3]) << 16
            | UInt32(bytes[4]) << 24
        return validated(Double(raw) / 100.0)
    }

    /// Report 1: 3 bytes `[0x01, lo, hi]`, little-endian UInt16, whole degrees.
    public static func degrees(fromReport1 bytes: [UInt8]) -> Double? {
        guard bytes.count >= 3, bytes[0] == 0x01 else { return nil }
        let raw = UInt16(bytes[1]) | UInt16(bytes[2]) << 8
        return validated(Double(raw))
    }

    private static func validated(_ degrees: Double) -> Double? {
        guard degrees >= minDegrees, degrees <= maxDegrees else { return nil }
        return degrees
    }
}
```

```swift
import Foundation
import IOKit
import IOKit.hid

public enum LidSupport: Equatable {
    case supported
    case presentButUnreadable(model: String)
    case unsupported(model: String)
}

public enum HardwareCompat {

    public static let vendorID = 0x05AC
    public static let productID = 0x8104
    public static let usagePage = 0x0020   // Sensor
    public static let usage = 0x008A       // Orientation

    /// The machine identifier, e.g. "Mac16,8".
    public static func hardwareModel() -> String {
        var size = 0
        sysctlbyname("hw.model", nil, &size, nil, 0)
        guard size > 0 else { return "unknown" }
        var buffer = [CChar](repeating: 0, count: size)
        sysctlbyname("hw.model", &buffer, &size, nil, 0)
        return String(cString: buffer)
    }

    /// Two-tier probe. Tier 1 matches the full sensor-page descriptor. Tier 2
    /// checks whether the product exists under any usage page at all, which
    /// distinguishes "your Mac has no sensor" from "your Mac has the sensor but
    /// exposes it on the vendor page where we cannot read it".
    public static func diagnose() -> LidSupport {
        let model = hardwareModel()

        if matchCount(["VendorID": vendorID,
                       "ProductID": productID,
                       "PrimaryUsagePage": usagePage,
                       "PrimaryUsage": usage]) > 0 {
            return .supported
        }

        if matchCount(["VendorID": vendorID, "ProductID": productID]) > 0 {
            return .presentButUnreadable(model: model)
        }

        return .unsupported(model: model)
    }

    private static func matchCount(_ matching: [String: Int]) -> Int {
        let manager = IOHIDManagerCreate(kCFAllocatorDefault, IOOptionBits(kIOHIDOptionsTypeNone))
        IOHIDManagerSetDeviceMatching(manager, matching as CFDictionary)
        IOHIDManagerOpen(manager, IOOptionBits(kIOHIDOptionsTypeNone))
        defer { IOHIDManagerClose(manager, IOOptionBits(kIOHIDOptionsTypeNone)) }
        guard let devices = IOHIDManagerCopyDevices(manager) as? Set<IOHIDDevice> else { return 0 }
        return devices.count
    }
}
```

```swift
import Foundation
import IOKit
import IOKit.hid

/// Opens the lid-angle HID device and polls it for the current angle.
///
/// Probes report 7 (hundredths of a degree) once at open time and uses it for
/// the lifetime of the connection if the device answers. Falls back to report 1
/// (whole degrees) otherwise.
public final class LidSensor {

    public var onAngle: ((Double) -> Void)?

    private let device: IOHIDDevice
    private var usesReport7 = false
    private var timer: DispatchSourceTimer?
    private let queue = DispatchQueue(label: "app.slant.sensor")

    private static let trackingInterval: DispatchTimeInterval = .microseconds(8_333) // 120Hz
    private static let idleInterval: DispatchTimeInterval = .milliseconds(100)        // 10Hz

    public init?() {
        let manager = IOHIDManagerCreate(kCFAllocatorDefault, IOOptionBits(kIOHIDOptionsTypeNone))
        let matching: [String: Int] = [
            "VendorID": HardwareCompat.vendorID,
            "ProductID": HardwareCompat.productID,
            "PrimaryUsagePage": HardwareCompat.usagePage,
            "PrimaryUsage": HardwareCompat.usage,
        ]
        IOHIDManagerSetDeviceMatching(manager, matching as CFDictionary)
        IOHIDManagerOpen(manager, IOOptionBits(kIOHIDOptionsTypeNone))
        guard let devices = IOHIDManagerCopyDevices(manager) as? Set<IOHIDDevice>,
              let found = devices.first else { return nil }
        device = found
        guard IOHIDDeviceOpen(device, IOOptionBits(kIOHIDOptionsTypeNone)) == kIOReturnSuccess
        else { return nil }
        usesReport7 = (readReport(id: 7, length: 5) != nil)
    }

    public func setTracking(_ active: Bool) {
        timer?.cancel()
        let t = DispatchSource.makeTimerSource(queue: queue)
        let interval = active ? Self.trackingInterval : Self.idleInterval
        t.schedule(deadline: .now(), repeating: interval)
        t.setEventHandler { [weak self] in self?.sample() }
        t.resume()
        timer = t
    }

    public func stop() {
        timer?.cancel()
        timer = nil
        IOHIDDeviceClose(device, IOOptionBits(kIOHIDOptionsTypeNone))
    }

    private func sample() {
        let degrees: Double?
        if usesReport7 {
            degrees = readReport(id: 7, length: 5).flatMap { LidReport.degrees(fromReport7: $0) }
        } else {
            degrees = readReport(id: 1, length: 3).flatMap { LidReport.degrees(fromReport1: $0) }
        }
        guard let value = degrees else { return }
        onAngle?(value)
    }

    private func readReport(id: Int, length: Int) -> [UInt8]? {
        var buffer = [UInt8](repeating: 0, count: length)
        var size = length
        let result = IOHIDDeviceGetReport(device, kIOHIDReportTypeFeature, CFIndex(id), &buffer, &size)
        guard result == kIOReturnSuccess, size >= length else { return nil }
        return buffer
    }
}
```

```swift
import Foundation

/// A critically damped spring integrated with semi-implicit Euler.
///
/// Critically damped means it converges as fast as possible without
/// overshooting, which is what a lid should feel like: it follows the hand and
/// settles, it never bounces. Driven per frame so the render rate is decoupled
/// from the sensor's polling cadence.
public struct CriticallyDampedSpring {

    public private(set) var value: Double
    public private(set) var velocity: Double = 0

    /// Angular frequency. Higher is stiffer. 16 tracks a hand closing a lid
    /// closely without feeling mechanical.
    public var frequency: Double

    /// Clamped so a stalled frame cannot destabilise the integrator.
    private static let maxTimeStep: Double = 1.0 / 30.0

    private static let restValueEpsilon: Double = 0.01
    private static let restVelocityEpsilon: Double = 0.01

    public init(value: Double, frequency: Double = 16) {
        self.value = value
        self.frequency = frequency
    }

    public var isAtRest: Bool {
        abs(velocity) < Self.restVelocityEpsilon
    }

    public mutating func advance(to target: Double, dt: Double) {
        guard dt > 0 else { return }
        var remaining = dt
        while remaining > 0 {
            let step = min(remaining, Self.maxTimeStep)
            remaining -= step
            let omega = frequency
            let acceleration = omega * omega * (target - value) - 2 * omega * velocity
            velocity += acceleration * step
            value += velocity * step
        }
        if abs(target - value) < Self.restValueEpsilon && isAtRest {
            value = target
            velocity = 0
        }
    }
}
```

```swift
import Foundation

/// Learns the angle at which this user habitually rests the lid, so there is no
/// threshold setting to explain or get wrong.
///
/// A hysteresis dwell detector: the candidate angle resets whenever the lid
/// moves more than `moveThreshold`, and only becomes the anchor once it has
/// held still for `requiredDwell`. That rejects both sensor jitter and the
/// transit through intermediate angles while the lid is actually moving.
public struct LidStillness {

    public private(set) var anchor: Double

    private var candidate: Double
    private var dwell: Double = 0

    /// Degrees of movement that reset the dwell timer.
    public static let moveThreshold: Double = 2.0
    /// Seconds of stillness required before the anchor moves.
    public static let requiredDwell: Double = 1.0

    public init(seed: Double = 100) {
        anchor = seed
        candidate = seed
    }

    public mutating func update(angle: Double, dt: Double) {
        guard dt > 0 else { return }
        if abs(angle - candidate) >= Self.moveThreshold {
            candidate = angle
            dwell = 0
            return
        }
        dwell += dt
        if dwell >= Self.requiredDwell, abs(candidate - anchor) >= Self.moveThreshold {
            anchor = candidate
        }
    }
}
```

```swift
            excludingApplications: ownApplications,
```

```swift
import Foundation

/// A 2D projective transform mapping the unit square onto an arbitrary
/// convex quadrilateral (Heckbert's square-to-quad).
///
/// The renderer uses the inverse direction: every output pixel is mapped back
/// into picture space, so the fold needs no geometry subdivision at all — one
/// full-screen triangle and a matrix produce true perspective.
///
/// Approach follows sumimakito's Mac-Duo (Apache-2.0).
public struct Homography: Equatable {

    public let a, b, c: Double
    public let d, e, f: Double
    public let g, h: Double
    // The ninth coefficient is fixed at 1.

    /// `corners` are the images of (0,0), (1,0), (1,1), (0,1) in that order.
    public static func squareToQuad(_ corners: [(x: Double, y: Double)]) -> Homography {
        precondition(corners.count == 4, "a quad needs exactly four corners")
        let (x0, y0) = corners[0]
        let (x1, y1) = corners[1]
        let (x2, y2) = corners[2]
        let (x3, y3) = corners[3]

        let dx1 = x1 - x2, dx2 = x3 - x2, dx3 = x0 - x1 + x2 - x3
        let dy1 = y1 - y2, dy2 = y3 - y2, dy3 = y0 - y1 + y2 - y3

        if dx3 == 0 && dy3 == 0 {
            // Parallelogram: the transform is affine.
            return Homography(
                a: x1 - x0, b: x2 - x1, c: x0,
                d: y1 - y0, e: y2 - y1, f: y0,
                g: 0, h: 0
            )
        }

        let denominator = dx1 * dy2 - dy1 * dx2
        guard denominator != 0 else {
            // Degenerate quad; fall back to identity rather than produce NaNs.
            return Homography(a: 1, b: 0, c: 0, d: 0, e: 1, f: 0, g: 0, h: 0)
        }

        let g = (dx3 * dy2 - dy3 * dx2) / denominator
        let h = (dx1 * dy3 - dy1 * dx3) / denominator

        return Homography(
            a: x1 - x0 + g * x1, b: x3 - x0 + h * x3, c: x0,
            d: y1 - y0 + g * y1, e: y3 - y0 + h * y3, f: y0,
            g: g, h: h
        )
    }

    public func apply(x: Double, y: Double) -> (x: Double, y: Double) {
        let denominator = g * x + h * y + 1
        guard denominator != 0 else { return (x, y) }
        return ((a * x + b * y + c) / denominator,
                (d * x + e * y + f) / denominator)
    }

    /// Column-major, for upload as a `float3x3`.
    public var floatColumns: [Float] {
        [Float(a), Float(d), Float(g),
         Float(b), Float(e), Float(h),
         Float(c), Float(f), 1]
    }
}
```

```swift
import Foundation

/// Projects the screen as a rigid panel hinged along its bottom edge.
///
/// The hinge stays put and the top edge recedes and narrows as the lid closes,
/// which is what produces the trapezoid the homography then maps through.
/// Perspective divide follows Mac-Duo's `scale = depth / (depth + y * sin(separation))`.
public enum FoldGeometry {

    /// How far the panel lays back at full fold, in radians.
    public static let maximumSeparation: Double = 75 * .pi / 180

    /// Viewer distance in screen-heights. Smaller is a wider lens and a more
    /// dramatic fold; 2.2 reads as "physical" without looking like a fisheye.
    public static let depth: Double = 2.2

    /// Images of (0,0), (1,0), (1,1), (0,1) — bottom-left, bottom-right,
    /// top-right, top-left, with the hinge along y = 0.
    public static func corners(progress: Double) -> [(x: Double, y: Double)] {
        let clamped = min(max(progress, 0), 1)
        let separation = clamped * maximumSeparation
        let sine = sin(separation)
        let cosine = cos(separation)

        func project(_ x: Double, _ y: Double) -> (x: Double, y: Double) {
            let scale = depth / (depth + y * sine)
            return (0.5 + (x - 0.5) * scale, y * cosine * scale)
        }

        return [project(0, 0), project(1, 0), project(1, 1), project(0, 1)]
    }
}

public extension Homography {
    /// The inverse transform, column-major, for upload as a `float3x3`.
    ///
    /// The shader maps each output pixel back into picture space, so it needs
    /// quad-to-square, not square-to-quad.
    var inverseColumns: [Float] {
        let i = 1.0
        let determinant =
            a * (e * i - f * h) -
            b * (d * i - f * g) +
            c * (d * h - e * g)
        guard determinant != 0 else {
            return [1, 0, 0, 0, 1, 0, 0, 0, 1]
        }
        let inverseDeterminant = 1.0 / determinant

        let a2 = (e * i - f * h) * inverseDeterminant
        let b2 = (c * h - b * i) * inverseDeterminant
        let c2 = (b * f - c * e) * inverseDeterminant
        let d2 = (f * g - d * i) * inverseDeterminant
        let e2 = (a * i - c * g) * inverseDeterminant
        let f2 = (c * d - a * f) * inverseDeterminant
        let g2 = (d * h - e * g) * inverseDeterminant
        let h2 = (b * g - a * h) * inverseDeterminant
        let i2 = (a * e - b * d) * inverseDeterminant

        return [Float(a2), Float(d2), Float(g2),
                Float(b2), Float(e2), Float(h2),
                Float(c2), Float(f2), Float(i2)]
    }
}
```

```metal
#include <metal_stdlib>
using namespace metal;

struct FoldUniforms {
    float3x3 inverseHomography;
    float    blur;           // 0...1
    float    dim;            // 0...1
    float    maxMipLevel;
    float    maxBlurRadius;  // in source pixels
};

struct VertexOut {
    float4 position [[position]];
    float2 uv;
};

// One oversized triangle covers the screen with no vertex buffer.
vertex VertexOut foldVertex(uint vertexID [[vertex_id]]) {
    float2 positions[3] = { float2(-1.0, -3.0), float2(-1.0, 1.0), float2(3.0, 1.0) };
    VertexOut out;
    out.position = float4(positions[vertexID], 0.0, 1.0);
    float2 uv = positions[vertexID] * 0.5 + 0.5;
    out.uv = float2(uv.x, uv.y);
    return out;
}

fragment float4 foldFragment(VertexOut in [[stage_in]],
                             texture2d<float> picture [[texture(0)]],
                             constant FoldUniforms &uniforms [[buffer(0)]]) {
    constexpr sampler linearSampler(filter::linear,
                                    mip_filter::linear,
                                    address::clamp_to_edge);

    // Map this output pixel back into picture space.
    float3 source = uniforms.inverseHomography * float3(in.uv, 1.0);
    float2 texCoord = source.xy / source.z;

    // Outside the folded panel is fully transparent, so the desktop below shows.
    if (texCoord.x < 0.0 || texCoord.x > 1.0 || texCoord.y < 0.0 || texCoord.y > 1.0) {
        return float4(0.0);
    }

    // Blur is free: sample the pre-built Gaussian pyramid at a continuous level.
    float mipLevel = clamp(log2(max(uniforms.blur * uniforms.maxBlurRadius, 1.0)),
                           0.0, uniforms.maxMipLevel);

    // The pyramid stores y top-down; flip to match our hinge-at-y=0 convention.
    float4 colour = picture.sample(linearSampler,
                                   float2(texCoord.x, 1.0 - texCoord.y),
                                   level(mipLevel));

    // Dim in linear light so the falloff reads as shadow, not as a grey veil.
    colour.rgb *= pow(1.0 - uniforms.dim, 2.2);
    colour.a = 1.0;
    return colour;
}
```

```swift
        descriptor.colorAttachments[0].destinationRGBBlendFactor = .oneMinusSourceAlpha
        descriptor.colorAttachments[0].sourceAlphaBlendFactor = .one
        descriptor.colorAttachments[0].destinationAlphaBlendFactor = .oneMinusSourceAlpha

        guard let pipeline = try? device.makeRenderPipelineState(descriptor: descriptor)
        else { return nil }

        self.device = device
        self.layer = layer
        self.queue = queue
        self.pipeline = pipeline
        self.pyramid = MPSImageGaussianPyramid(device: device, centerWeight: 0.375)
    }

    public func render(texture: MTLTexture, progress: Double) {
        guard let drawable = layer.nextDrawable(),
              let commandBuffer = queue.makeCommandBuffer() else { return }

        let mip = mipTexture(matching: texture)

        // Copy the captured frame into level 0, then build the pyramid.
        if let blit = commandBuffer.makeBlitCommandEncoder() {
            blit.copy(from: texture,
                      sourceSlice: 0, sourceLevel: 0,
                      sourceOrigin: MTLOrigin(x: 0, y: 0, z: 0),
                      sourceSize: MTLSize(width: texture.width,
                                          height: texture.height, depth: 1),
                      to: mip,
                      destinationSlice: 0, destinationLevel: 0,
                      destinationOrigin: MTLOrigin(x: 0, y: 0, z: 0))
            blit.endEncoding()
        }
        pyramid.encode(commandBuffer: commandBuffer, inPlaceTexture: &{ mip }())

        let corners = FoldGeometry.corners(progress: progress)
        let columns = Homography.squareToQuad(corners).inverseColumns
        var uniforms = Uniforms(
            inverseHomography: simd_float3x3(
                SIMD3(columns[0], columns[1], columns[2]),
                SIMD3(columns[3], columns[4], columns[5]),
                SIMD3(columns[6], columns[7], columns[8])
            ),
            blur: Float(progress),
            dim: Float(progress) * Self.maximumDim,
            maxMipLevel: Float(mip.mipmapLevelCount - 1),
            maxBlurRadius: Self.maximumBlurRadius
        )

        let passDescriptor = MTLRenderPassDescriptor()
        passDescriptor.colorAttachments[0].texture = drawable.texture
        passDescriptor.colorAttachments[0].loadAction = .clear
        passDescriptor.colorAttachments[0].storeAction = .store
        passDescriptor.colorAttachments[0].clearColor = MTLClearColor(red: 0, green: 0, blue: 0, alpha: 0)

        guard let encoder = commandBuffer.makeRenderCommandEncoder(descriptor: passDescriptor)
        else { return }
        encoder.setRenderPipelineState(pipeline)
        encoder.setFragmentTexture(mip, index: 0)
        encoder.setFragmentBytes(&uniforms, length: MemoryLayout<Uniforms>.stride, index: 0)
        encoder.drawPrimitives(type: .triangle, vertexStart: 0, vertexCount: 3)
        encoder.endEncoding()

        commandBuffer.present(drawable)
        commandBuffer.commit()
    }

    private func mipTexture(matching source: MTLTexture) -> MTLTexture {
        if let existing = mipTexture,
           existing.width == source.width, existing.height == source.height {
            return existing
        }
        let descriptor = MTLTextureDescriptor.texture2DDescriptor(
            pixelFormat: source.pixelFormat,
            width: source.width,
            height: source.height,
            mipmapped: true
        )
        descriptor.usage = [.shaderRead, .shaderWrite]
        descriptor.storageMode = .private
        let created = device.makeTexture(descriptor: descriptor)!
        mipTexture = created
        return created
    }
}
```

```swift
import AppKit
import Metal
import QuartzCore
import LidSensor
import LidMotion
import DesktopCapture
import FoldOverlay
import FoldRenderer

/// Owns the whole pipeline: sensor to spring to renderer to overlay.
public final class FoldController {

    public var onFailure: ((String) -> Void)?

    private let presence = PresenceWindow()
    private var sensor: LidSensor?
    private var capture: DesktopCapture?
    private var overlay: FoldOverlayWindow?
    private var renderer: FoldRenderer?
    private var displayLink: CADisplayLink?

    private var spring = CriticallyDampedSpring(value: 0, frequency: 16)
    private var stillness = LidStillness(seed: 100)
    private var targetProgress: Double = 0
    private var latestTexture: MTLTexture?
    private var lastTimestamp: CFTimeInterval = 0

    public init() {}

    public func start() async {
        presence.keepAlive()

        switch HardwareCompat.diagnose() {
        case .supported:
            break
        case .presentButUnreadable(let model):
            onFailure?("""
            Slant found the lid-angle sensor on this \(model), but macOS is \
            exposing it on the vendor page where it cannot be read.
            """)
            return
        case .unsupported(let model):
            onFailure?("""
            This \(model) has no lid-angle sensor. Slant needs one, and no \
            software can substitute for it.
            """)
            return
        }

        guard let device = MTLCreateSystemDefaultDevice() else {
            onFailure?("Slant could not open a Metal device.")
            return
        }
        guard let screen = NSScreen.screens.first(where: {
            guard let number = $0.deviceDescription[.init("NSScreenNumber")] as? NSNumber
            else { return false }
            return CGDisplayIsBuiltin(CGDirectDisplayID(number.uint32Value)) != 0
        }) else {
            onFailure?("Slant could not find the built-in display.")
            return
        }

        let window = FoldOverlayWindow(screen: screen)
        guard let foldRenderer = FoldRenderer(device: device, layer: window.metalLayer) else {
            onFailure?("Slant could not build its Metal pipeline.")
            return
        }
        overlay = window
        renderer = foldRenderer

        let desktopCapture = DesktopCapture(device: device)
        desktopCapture.onFrame = { [weak self] texture in
            self?.latestTexture = texture
        }
        do {
            try await desktopCapture.start()
        } catch CaptureError.permissionDenied {
            onFailure?("""
            Slant needs Screen Recording permission to see the desktop it is \
            folding. Open System Settings > Privacy & Security > Screen & \
            System Audio Recording and enable Slant. Nothing is recorded and \
            nothing leaves your Mac.
            """)
            return
        } catch {
            onFailure?("Slant could not start screen capture: \(error.localizedDescription)")
            return
        }
        capture = desktopCapture

        let lidSensor = LidSensor()
        lidSensor?.onAngle = { [weak self] angle in
            DispatchQueue.main.async { self?.receive(angle: angle) }
        }
        lidSensor?.setTracking(true)
        sensor = lidSensor

        startDisplayLink(on: window)
    }

    public func stop() {
        displayLink?.invalidate()
        displayLink = nil
        sensor?.stop()
        sensor = nil
        capture?.stop()
        capture = nil
        overlay?.hide()
        overlay = nil
        renderer = nil
        latestTexture = nil
    }

    private func receive(angle: Double) {
        stillness.update(angle: angle, dt: 1.0 / 120.0)
        targetProgress = FoldProgress.progress(angle: angle, openAngle: stillness.anchor)
        if targetProgress > 0 || !spring.isAtRest {
            displayLink?.isPaused = false
            overlay?.show()
        }
    }

    private func startDisplayLink(on window: FoldOverlayWindow) {
        guard let view = window.contentView else { return }
        let link = view.displayLink(target: self, selector: #selector(tick(_:)))
        // Capped at 60 even on ProMotion: the fold is brief and 120Hz here is
        // pure battery cost for no visible benefit.
        link.preferredFrameRateRange = CAFrameRateRange(minimum: 30, maximum: 60, preferred: 60)
        link.add(to: .main, forMode: .common)
        link.isPaused = true
        displayLink = link
    }

    @objc private func tick(_ link: CADisplayLink) {
        let now = link.timestamp
        let dt = lastTimestamp == 0 ? 1.0 / 60.0 : now - lastTimestamp
        lastTimestamp = now

        spring.advance(to: targetProgress, dt: dt)

        if let texture = latestTexture {
            renderer?.render(texture: texture, progress: spring.value)
        }

        // Idle costs nothing: once the spring settles at fully open, stop.
        if spring.isAtRest && spring.value <= 0.001 && targetProgress <= 0.001 {
            link.isPaused = true
            lastTimestamp = 0
            overlay?.hide()
        }
    }
}
```

```swift
import AppKit

/// Watches the events that invalidate a running capture or HID connection.
public final class LifecycleObserver {

    private let onSleep: () -> Void
    private let onWake: () -> Void
    private let onScreensChanged: () -> Void

    public init(onSleep: @escaping () -> Void,
                onWake: @escaping () -> Void,
                onScreensChanged: @escaping () -> Void) {
        self.onSleep = onSleep
        self.onWake = onWake
        self.onScreensChanged = onScreensChanged
    }

    public func observe() {
        let workspace = NSWorkspace.shared.notificationCenter
        workspace.addObserver(forName: NSWorkspace.willSleepNotification,
                              object: nil, queue: .main) { [weak self] _ in self?.onSleep() }
        workspace.addObserver(forName: NSWorkspace.screensDidSleepNotification,
                              object: nil, queue: .main) { [weak self] _ in self?.onSleep() }
        workspace.addObserver(forName: NSWorkspace.didWakeNotification,
                              object: nil, queue: .main) { [weak self] _ in self?.onWake() }
        workspace.addObserver(forName: NSWorkspace.screensDidWakeNotification,
                              object: nil, queue: .main) { [weak self] _ in self?.onWake() }
        NotificationCenter.default.addObserver(
            forName: NSApplication.didChangeScreenParametersNotification,
            object: nil, queue: .main
        ) { [weak self] _ in self?.onScreensChanged() }
    }
}
```

```swift
        await start()

            try? await Task.sleep(nanoseconds: 1_000_000_000)
            reconnect(attemptsRemaining: attemptsRemaining - 1)
        }
    }
```

### Task 16: Signing, notarisation and release

**Files:**
- Modify: `Makefile`

**Interfaces:**
- Consumes: `make build` from Task 1.
- Produces: `make dmg`, a notarised, stapled `Slant.dmg`.

**Prerequisite:** an Apple Developer Program membership (99 USD/year). This is the only hard cash cost in the project, and it buys past the Gatekeeper warning that hinge currently subjects its users to — a genuine quality gap over the closest competitor.

- [ ] **Step 1: Add signing and notarisation targets to the `Makefile`**

```make
TEAM_ID ?= REPLACE_WITH_TEAM_ID
SIGN_ID ?= Developer ID Application: REPLACE_WITH_NAME ($(TEAM_ID))
KEYCHAIN_PROFILE ?= slant-notary

.PHONY: sign notarize dmg

sign: build
	codesign --force --deep --options runtime --timestamp \
		--sign "$(SIGN_ID)" $(BUNDLE)
	codesign --verify --strict --verbose=2 $(BUNDLE)

dmg: sign
	rm -f Slant.dmg
	hdiutil create -volname Slant -srcfolder $(BUNDLE) -ov -format UDZO Slant.dmg
	codesign --force --sign "$(SIGN_ID)" --timestamp Slant.dmg

notarize: dmg
	xcrun notarytool submit Slant.dmg \
		--keychain-profile "$(KEYCHAIN_PROFILE)" --wait
	xcrun stapler staple Slant.dmg
	xcrun stapler validate Slant.dmg
	@echo "Slant.dmg is notarised and stapled."
```

Note: the app is deliberately **not sandboxed**, so no entitlements file is used. `--options runtime` (hardened runtime) is required for notarisation and is compatible with IOHID access.
